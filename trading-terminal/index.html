About Northmark

Northmark is an independent charting and research app. It is not TradingView, and it is not affiliated with Binance or Coinbase.

Binance

Public market data from data-api.binance.vision and the websocket at data-stream.binance.vision. No API key. Spot symbols quoted in USDT. One request returns at most 1000 candles. Live updates are kline events. The main api.binance.com host can refuse some networks; this app does not call it.

Coinbase Exchange

Public REST at api.exchange.coinbase.com and the matches websocket. No API key. USD products. Each candle request is capped at 300 bars, and Northmark asks for four pages. 1m, 5m, 15m, 1h, and 1d are native. 4h and 1w are aggregated here from 1h and 1d. The candle response can be cached by the venue for a few minutes; the open candle is updated from matches.

What is not included

No stock feed. No API key is required, and this app does not use a stock source that failed a keyless browser check. Nothing here places orders.

Drawings and the watchlist stay in local storage on this device. Times on the chart are UTC.
